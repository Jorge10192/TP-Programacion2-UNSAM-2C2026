# WALOS

Sistema de gestión para un emprendimiento de productos alimenticios para mascotas.

## Objetivo

Centralizar la gestión de:

- proveedores y compras
- producción
- lotes
- stock
- ventas en ferias
- promociones
- pedidos y reservas
- pagos
- análisis de ventas
- costos

## Estado

Proyecto en etapa de análisis y diseño.
