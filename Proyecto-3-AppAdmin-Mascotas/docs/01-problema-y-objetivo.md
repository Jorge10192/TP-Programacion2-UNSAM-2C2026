# Problema

WALOS produce bocaditos y tortas para mascotas y comercializa principalmente
en ferias.

Actualmente utiliza herramientas externas para registrar ventas, pero existen
dificultades para gestionar promociones y descuentos.

La información de proveedores, compras, producción, stock y ventas se encuentra
distribuida entre distintas herramientas o registros.

Además, WALOS puede operar simultáneamente en diferentes ferias, por lo que
necesita conocer el stock disponible en cada punto de venta y permitir que
varias personas trabajen al mismo tiempo.

También necesita información histórica para analizar:

- ventas por feria
- ventas por producto
- ventas mensuales
- costos de producción
- proveedores
- rentabilidad
