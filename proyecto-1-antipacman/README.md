# Idea principal: 
Organizar una version de pacman donde se utilicen a los fantasmas para capturar a los pacman.
Funcionalidades pensadas:
1) Que sea un juego colaborativo multijugador.
2) Que pacman juegue cada vez mejor con algun entrenamiento/division de dificultades

# Usabilidad:
Lo ideal seria que el juego sea de facil acceso y multiplataforma, que con un link de internet o invitacion personal
pueda generarse una sala comun donde se organice la partida antes de iniciarla.

# Extension de idea:
1) Extension de jugabilidad:
- Permitir usar a los pacman habilidades o facilidades.
- Permitir a los fantasmas tambien usar algun tipo de beneficio adicional.
- Permitir editar el mapa
- Permitir crear bandos de juego fantasmas y pacmans para jugar la misma partida
  
2) Cargar estadisticas/perfil de jugadores
3) Crear reuniones virtuales con acceso publico o reuniones privadas
4) Crear chat o medio de comunicacion entre usuarios.
